# 📱 Smart Phone ASCII Showcase

A simple Python project that prints beautiful smartphone-style ASCII art directly in the terminal.

## ✨ Features

- Modern smartphone ASCII UI
- 3D phone perspective design
- Cyberpunk terminal style
- Unicode + emoji support
- Lightweight and beginner-friendly
